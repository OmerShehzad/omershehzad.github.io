## Selected Research and Academic Projects

### 1. Credit Card Fraud Detection Using Machine Learning

MSc dissertation investigating machine learning techniques for identifying fraudulent financial transactions through predictive modelling and comparative model evaluation.

[View GitHub Repository](https://github.com/OmerShehzad/PREDICATIVE-MODELLING-FOR-CREDIT-CARD-FRUAD-DETECTION-USING-MACHINE-LEARNING)

### 2. Heart Disease Prediction Using Machine Learning

Comparative evaluation of machine learning classification algorithms for heart disease prediction using exploratory data analysis, feature analysis and model optimisation.

[View GitHub Repository](https://github.com/OmerShehzad/Heart-Disease-Prediction-Using-Machine-Learning)

### 3. SpaceX Falcon 9 Landing Prediction

Predictive modelling and data analysis to investigate factors influencing the successful landing of the Falcon 9 first-stage booster.

[View GitHub Repository](https://github.com/OmerShehzad/Predict-if-Spacex-Falcon-9-first-stage-will-land-successfully)

### 4. Global Life Expectancy Analysis

Interactive data visualisation and analytical dashboard exploring global life expectancy patterns and associated socioeconomic and health indicators using Microsoft Power BI.

[View GitHub Repository](https://github.com/OmerShehzad/Life-Expectancy-Dashboard-and-analysis-using-Power-BI)
